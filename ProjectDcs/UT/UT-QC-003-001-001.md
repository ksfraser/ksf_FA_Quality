## Unit Test

### Related FR
FR-QC-003-002

BR-QC-003-calibration

### Test Class
`\Tests\Unit\CalibrationSchedulerTest`

### Test Method
`testCalculateNextDueDateWithVariousIntervals`

### Description

Verify calibration scheduler correctly calculates next due dates for all interval types (monthly, quarterly, semiannual, annual) and correctly detects overdue and due-soon devices.

### Test Scenario

#### Test Data

| Input | Value |
|-------|-------|
| Last Calibration Date | 2026-01-15 |
| Monthly Next Due | 2026-02-15 |
| Quarterly Next Due | 2026-04-15 |
| Semiannual Next Due | 2026-07-15 |
| Annual Next Due | 2027-01-15 |

#### Test Code

```php
<?php
declare(strict_types=1);

namespace Tests\Unit;

use PHPUnit\Framework\TestCase;
use ksfraser\FrontAccounting\Quality\Services\CalibrationScheduler;

class CalibrationSchedulerTest extends TestCase
{
    /** @var CalibrationScheduler */
    private $scheduler;

    protected function setUp(): void
    {
        $this->scheduler = new CalibrationScheduler();
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify next due date calculation for monthly interval
     *
     * Last calibration: 2026-01-15
     * Expected next due: 2026-02-15 (January 15 + 1 month)
     */
    public function testCalculateNextDueDateMonthly(): void
    {
        $lastCalibration = new \DateTime('2026-01-15');
        $expectedDue = new \DateTime('2026-02-15');

        $nextDue = $this->scheduler->calculateNextDueDate(
            $lastCalibration,
            CalibrationScheduler::INTERVAL_MONTHLY
        );

        $this->assertEquals($expectedDue->format('Y-m-d'), $nextDue->format('Y-m-d'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify next due date calculation for quarterly interval
     *
     * Last calibration: 2026-01-15
     * Expected next due: 2026-04-15 (January 15 + 3 months)
     */
    public function testCalculateNextDueDateQuarterly(): void
    {
        $lastCalibration = new \DateTime('2026-01-15');
        $expectedDue = new \DateTime('2026-04-15');

        $nextDue = $this->scheduler->calculateNextDueDate(
            $lastCalibration,
            CalibrationScheduler::INTERVAL_QUARTERLY
        );

        $this->assertEquals($expectedDue->format('Y-m-d'), $nextDue->format('Y-m-d'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify next due date calculation for semiannual interval
     *
     * Last calibration: 2026-01-15
     * Expected next due: 2026-07-15 (January 15 + 6 months)
     */
    public function testCalculateNextDueDateSemiannual(): void
    {
        $lastCalibration = new \DateTime('2026-01-15');
        $expectedDue = new \DateTime('2026-07-15');

        $nextDue = $this->scheduler->calculateNextDueDate(
            $lastCalibration,
            CalibrationScheduler::INTERVAL_SEMIANNUAL
        );

        $this->assertEquals($expectedDue->format('Y-m-d'), $nextDue->format('Y-m-d'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify next due date calculation for annual interval
     *
     * Last calibration: 2026-01-15
     * Expected next due: 2027-01-15 (January 15 + 12 months)
     */
    public function testCalculateNextDueDateAnnual(): void
    {
        $lastCalibration = new \DateTime('2026-01-15');
        $expectedDue = new \DateTime('2027-01-15');

        $nextDue = $this->scheduler->calculateNextDueDate(
            $lastCalibration,
            CalibrationScheduler::INTERVAL_ANNUAL
        );

        $this->assertEquals($expectedDue->format('Y-m-d'), $nextDue->format('Y-m-d'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify end-of-month handling: January 31 + 1 month = February 28/29
     */
    public function testEndOfMonthHandling(): void
    {
        $lastCalibration = new \DateTime('2026-01-31');
        $expectedDue = new \DateTime('2026-02-28');

        $nextDue = $this->scheduler->addMonthsWithEndOfMonthHandling(
            $lastCalibration,
            1
        );

        $this->assertEquals($expectedDue->format('Y-m-d'), $nextDue->format('Y-m-d'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify overdue detection: date in the past returns true
     */
    public function testIsOverdueReturnsTrueForPastDate(): void
    {
        $pastDue = new \DateTime('2026-09-01');

        $this->assertTrue($this->scheduler->isOverdue($pastDue));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify overdue detection: future date returns false
     */
    public function testIsOverdueReturnsFalseForFutureDate(): void
    {
        $futureDue = new \DateTime('2027-01-01');

        $this->assertFalse($this->scheduler->isOverdue($futureDue));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify due soon detection: date within 7 days returns true
     */
    public function testIsDueSoonReturnsTrueWithinThreshold(): void
    {
        $today = new \DateTime('today');
        $dueSoon = clone $today;
        $dueSoon->modify('+5 days');

        $this->assertTrue($this->scheduler->isDueSoon($dueSoon, 7));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify due soon detection: date beyond 7 days returns false
     */
    public function testIsDueSoonReturnsFalseBeyondThreshold(): void
    {
        $today = new \DateTime('today');
        $notDueSoon = clone $today;
        $notDueSoon->modify('+10 days');

        $this->assertFalse($this->scheduler->isDueSoon($notDueSoon, 7));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify getMonthsForInterval returns correct values
     */
    public function testGetMonthsForInterval(): void
    {
        $this->assertSame(1, $this->scheduler->getMonthsForInterval('monthly'));
        $this->assertSame(3, $this->scheduler->getMonthsForInterval('quarterly'));
        $this->assertSame(6, $this->scheduler->getMonthsForInterval('semiannual'));
        $this->assertSame(12, $this->scheduler->getMonthsForInterval('annual'));
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify getMonthsForInterval throws exception for invalid interval
     */
    public function testGetMonthsForIntervalThrowsForInvalidInterval(): void
    {
        $this->expectException(\InvalidArgumentException::class);
        $this->scheduler->getMonthsForInterval('invalid');
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify getDaysUntilDue calculates correctly
     */
    public function testGetDaysUntilDue(): void
    {
        $today = new \DateTime('today');
        $fiveDaysLater = clone $today;
        $fiveDaysLater->modify('+5 days');

        $days = $this->scheduler->getDaysUntilDue($fiveDaysLater);

        $this->assertSame(5, $days);
    }

    /**
     * @BABOK Related: FR-QC-003-002, BR-QC-003
     *
     * Verify getDaysUntilDue for past date returns negative
     */
    public function testGetDaysUntilDueNegativeForPastDate(): void
    {
        $today = new \DateTime('today');
        $threeDaysAgo = clone $today;
        $threeDaysAgo->modify('-3 days');

        $days = $this->scheduler->getDaysUntilDue($threeDaysAgo);

        $this->assertSame(-3, $days);
    }
}
```

### Pass Criteria

1. Monthly interval calculates next due as last + 1 month
2. Quarterly interval calculates next due as last + 3 months
3. Semiannual interval calculates next due as last + 6 months
4. Annual interval calculates next due as last + 12 months
5. End-of-month dates handled correctly
6. Overdue detection works for past dates
7. Due soon detection works within threshold
8. Invalid interval throws exception

- PHPUnit installed
- `ksfraser\FrontAccounting\Quality\Services\CalibrationScheduler` class available

### Postconditions

- No side effects on test data
- All assertions pass
