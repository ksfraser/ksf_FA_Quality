# FR-QC-003-003: Calibration Recording

## Version

## Author

## Created

## Status
Proposed

## Functional Requirement

### Related BR
BR-QC-003-calibration

### Description

The system SHALL allow authorized users to record calibration events with full measurement traceability and automatically update device due dates.

### Preconditions

1. User has Quality Technician or higher permission
2. Device exists and is in 'active' status
3. User is logged into FrontAccounting

### Postconditions

1. Calibration record created with unique ID
2. Device last_calibration_date updated
3. Device next_due_date recalculated
4. If out-of-tolerance, device status set to 'out_of_service'

### Functional Specification

#### 1. Calibration Record Form

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| Device | select | Yes | Active device |
| Calibration Date | date | Yes | Valid date, not future |
| Result | enum | Yes | pass, fail, out_of_tolerance |
| Technician Name | string | Yes | Max 255 chars |
| Technician ID | int | Yes | Valid user |
| Calibration Standard | string | No | Max 255 chars |
| Temperature | decimal | No | Numeric |
| Humidity | decimal | No | Numeric |
| As Found Reading | decimal | No | Numeric |
| As Left Reading | decimal | No | Numeric |
| Correction Factor | decimal | No | Numeric |
| Certificate Number | string | No | Max 100 chars |
| Certificate | file | No | PDF, max 10MB |
| Next Due Date | date | Yes | Calculated or manual override |
| Notes | text | No | Max 5000 chars |

#### 2. Business Rules

- Calibration date cannot be in the future
- If result = 'out_of_tolerance', device status → 'out_of_service'
- If result = 'fail', device status → 'out_of_service'
- Next due date auto-calculated from interval + calibration date
- Certificate uploaded to ksf_FA_Documents storage
- Technician ID must be valid FA user

#### 3. User Flow

```
1. Navigate to Quality > Calibration
2. Select device from list
3. Click "Record Calibration"
4. Enter calibration date
5. Select result (pass/fail/out_of_tolerance)
6. Enter technician name and ID
7. Optionally enter environmental conditions
8. Optionally enter as-found/as-left readings
9. Optionally enter calibration standard and certificate
10. Verify next due date (auto-calculated)
11. Optionally add notes
12. Save → Record created, device dates updated
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Entities;

class CalibrationRecord
{
    const RESULT_PASS = 'pass';
    const RESULT_FAIL = 'fail';
    const RESULT_OUT_OF_TOLERANCE = 'out_of_tolerance';

    const VALID_RESULTS = [
        self::RESULT_PASS,
        self::RESULT_FAIL,
        self::RESULT_OUT_OF_TOLERANCE,
    ];

    /** @var int|null */
    private $id;

    /** @var int */
    private $deviceId;

    /** @var \DateTime */
    private $calibrationDate;

    /** @var string */
    private $result;

    /** @var string */
    private $technicianName;

    /** @var int */
    private $technicianId;

    /** @var string|null */
    private $calibrationStandard;

    /** @var float|null */
    private $temperature;

    /** @var float|null */
    private $humidity;

    /** @var float|null */
    private $asFoundReading;

    /** @var float|null */
    private $asLeftReading;

    /** @var float|null */
    private $correctionFactor;

    /** @var string|null */
    private $certificateNumber;

    /** @var string|null */
    private $certificatePath;

    /** @var \DateTime */
    private $nextDueDate;

    /** @var string|null */
    private $notes;

    /** @var \DateTime */
    private $createdAt;

    public function __construct()
    {
        $this->createdAt = new \DateTime();
    }

    public function getId(): ?int
    {
        return $this->id;
    }

    public function setId(int $id): self
    {
        $this->id = $id;
        return $this;
    }

    public function getDeviceId(): int
    {
        return $this->deviceId;
    }

    public function setDeviceId(int $deviceId): self
    {
        $this->deviceId = $deviceId;
        return $this;
    }

    public function getCalibrationDate(): \DateTime
    {
        return $this->calibrationDate;
    }

    public function setCalibrationDate(\DateTime $calibrationDate): self
    {
        $today = new \DateTime('today');
        if ($calibrationDate > $today) {
            throw new \InvalidArgumentException('Calibration date cannot be in the future');
        }
        $this->calibrationDate = $calibrationDate;
        return $this;
    }

    public function getResult(): string
    {
        return $this->result;
    }

    public function setResult(string $result): self
    {
        if (!in_array($result, self::VALID_RESULTS, true)) {
            throw new \InvalidArgumentException('Invalid calibration result');
        }
        $this->result = $result;
        return $this;
    }

    public function getTechnicianName(): string
    {
        return $this->technicianName;
    }

    public function setTechnicianName(string $technicianName): self
    {
        $technicianName = trim($technicianName);
        if (empty($technicianName)) {
            throw new \InvalidArgumentException('Technician name cannot be empty');
        }
        if (strlen($technicianName) > 255) {
            throw new \InvalidArgumentException('Technician name cannot exceed 255 characters');
        }
        $this->technicianName = $technicianName;
        return $this;
    }

    public function getTechnicianId(): int
    {
        return $this->technicianId;
    }

    public function setTechnicianId(int $technicianId): self
    {
        $this->technicianId = $technicianId;
        return $this;
    }

    public function getCalibrationStandard(): ?string
    {
        return $this->calibrationStandard;
    }

    public function setCalibrationStandard(?string $calibrationStandard): self
    {
        if ($calibrationStandard !== null && strlen($calibrationStandard) > 255) {
            throw new \InvalidArgumentException('Calibration standard cannot exceed 255 characters');
        }
        $this->calibrationStandard = $calibrationStandard;
        return $this;
    }

    public function getTemperature(): ?float
    {
        return $this->temperature;
    }

    public function setTemperature(?float $temperature): self
    {
        $this->temperature = $temperature;
        return $this;
    }

    public function getHumidity(): ?float
    {
        return $this->humidity;
    }

    public function setHumidity(?float $humidity): self
    {
        $this->humidity = $humidity;
        return $this;
    }

    public function getAsFoundReading(): ?float
    {
        return $this->asFoundReading;
    }

    public function setAsFoundReading(?float $asFoundReading): self
    {
        $this->asFoundReading = $asFoundReading;
        return $this;
    }

    public function getAsLeftReading(): ?float
    {
        return $this->asLeftReading;
    }

    public function setAsLeftReading(?float $asLeftReading): self
    {
        $this->asLeftReading = $asLeftReading;
        return $this;
    }

    public function getCorrectionFactor(): ?float
    {
        return $this->correctionFactor;
    }

    public function setCorrectionFactor(?float $correctionFactor): self
    {
        $this->correctionFactor = $correctionFactor;
        return $this;
    }

    public function getCertificateNumber(): ?string
    {
        return $this->certificateNumber;
    }

    public function setCertificateNumber(?string $certificateNumber): self
    {
        if ($certificateNumber !== null && strlen($certificateNumber) > 100) {
            throw new \InvalidArgumentException('Certificate number cannot exceed 100 characters');
        }
        $this->certificateNumber = $certificateNumber;
        return $this;
    }

    public function getCertificatePath(): ?string
    {
        return $this->certificatePath;
    }

    public function setCertificatePath(?string $certificatePath): self
    {
        $this->certificatePath = $certificatePath;
        return $this;
    }

    public function getNextDueDate(): \DateTime
    {
        return $this->nextDueDate;
    }

    public function setNextDueDate(\DateTime $nextDueDate): self
    {
        $this->nextDueDate = $nextDueDate;
        return $this;
    }

    public function getNotes(): ?string
    {
        return $this->notes;
    }

    public function setNotes(?string $notes): self
    {
        if ($notes !== null && strlen($notes) > 5000) {
            throw new \InvalidArgumentException('Notes cannot exceed 5000 characters');
        }
        $this->notes = $notes;
        return $this;
    }

    public function getCreatedAt(): \DateTime
    {
        return $this->createdAt;
    }

    public function isCompliant(): bool
    {
        return $this->result === self::RESULT_PASS;
    }

    public function requiresFollowUp(): bool
    {
        return in_array($this->result, [
            self::RESULT_FAIL,
            self::RESULT_OUT_OF_TOLERANCE,
        ], true);
    }

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'device_id' => $this->deviceId,
            'calibration_date' => $this->calibrationDate->format('Y-m-d'),
            'result' => $this->result,
            'technician_name' => $this->technicianName,
            'technician_id' => $this->technicianId,
            'calibration_standard' => $this->calibrationStandard,
            'temperature' => $this->temperature,
            'humidity' => $this->humidity,
            'as_found_reading' => $this->asFoundReading,
            'as_left_reading' => $this->asLeftReading,
            'correction_factor' => $this->correctionFactor,
            'certificate_number' => $this->certificateNumber,
            'certificate_path' => $this->certificatePath,
            'next_due_date' => $this->nextDueDate->format('Y-m-d'),
            'notes' => $this->notes,
            'created_at' => $this->createdAt->format('Y-m-d H:i:s'),
        ];
    }
}
```
