# FR-QC-002-005: Action Tracking

## Version
1.0.0

## Author
KSF Development Team

## Created
2026-09-07

## Status
Approved

## Functional Requirement

### Related BR
BR-QC-002-amdec-fmea

### Description

The system SHALL allow users to create, assign, and track follow-up actions for failure modes with high RPN values. Actions SHALL have due dates, responsible users, status tracking, and completion logging.

### Preconditions

1. Failure mode exists with RPN ≥ action threshold
2. User has edit permission on AMDEC project
3. User is logged in

### Postconditions

1. Action created and linked to failure mode
2. Responsible user notified (if notification enabled)
3. Due date tracked
4. Status changes logged

### Functional Specification

#### 1. Action Entity

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| Failure Mode ID | int | Yes | FK to failure_modes |
| Action Description | text | Yes | Max 5000 chars |
| Responsible User ID | int | Yes | FK to users |
| Due Date | date | Yes | Must be future or today |
| Status | enum | Yes | pending/in_progress/completed/cancelled |
| Result | text | No | Max 5000 chars |
| Completed At | datetime | No | Set on completion |

#### 2. Status Lifecycle

```
pending → in_progress → completed
              ↓
           cancelled
```

#### 3. Business Rules

- Actions can only be created for failure modes
- Due date cannot be in the past
- Only responsible user or manager can mark complete
- Completion requires result description
- Cancelled actions cannot be reopened

#### 4. Overdue Detection

- Actions with due_date < today AND status NOT in (completed, cancelled) are overdue
- Overdue actions highlighted in UI
- Overdue count shown in project summary

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Entities;

class AmdecAction
{
    const STATUS_PENDING = 'pending';
    const STATUS_IN_PROGRESS = 'in_progress';
    const STATUS_COMPLETED = 'completed';
    const STATUS_CANCELLED = 'cancelled';

    private static $validStatuses = [
        self::STATUS_PENDING,
        self::STATUS_IN_PROGRESS,
        self::STATUS_COMPLETED,
        self::STATUS_CANCELLED,
    ];

    private static $allowedTransitions = [
        self::STATUS_PENDING => [self::STATUS_IN_PROGRESS, self::STATUS_CANCELLED],
        self::STATUS_IN_PROGRESS => [self::STATUS_COMPLETED, self::STATUS_CANCELLED],
        self::STATUS_COMPLETED => [],
        self::STATUS_CANCELLED => [],
    ];

    /** @var int|null */
    private $id;

    /** @var int */
    private $failureModeId;

    /** @var string */
    private $actionDescription;

    /** @var int */
    private $responsibleUserId;

    /** @var \DateTime */
    private $dueDate;

    /** @var string */
    private $status = self::STATUS_PENDING;

    /** @var string|null */
    private $result;

    /** @var \DateTime|null */
    private $completedAt;

    /** @var \DateTime */
    private $createdAt;

    /** @var \DateTime */
    private $updatedAt;

    public function __construct()
    {
        $this->createdAt = new \DateTime();
        $this->updatedAt = new \DateTime();
    }

    public function getId(): ?int
    {
        return $this->id;
    }

    public function setId(int $id): self
    {
        $this->id = $id;
        return $this;
    }

    public function getFailureModeId(): int
    {
        return $this->failureModeId;
    }

    public function setFailureModeId(int $failureModeId): self
    {
        $this->failureModeId = $failureModeId;
        return $this;
    }

    public function getActionDescription(): string
    {
        return $this->actionDescription;
    }

    public function setActionDescription(string $actionDescription): self
    {
        $actionDescription = trim($actionDescription);
        if (empty($actionDescription)) {
            throw new \InvalidArgumentException('Action description cannot be empty');
        }
        if (strlen($actionDescription) > 5000) {
            throw new \InvalidArgumentException('Action description cannot exceed 5000 characters');
        }
        $this->actionDescription = $actionDescription;
        return $this;
    }

    public function getResponsibleUserId(): int
    {
        return $this->responsibleUserId;
    }

    public function setResponsibleUserId(int $responsibleUserId): self
    {
        if ($responsibleUserId <= 0) {
            throw new \InvalidArgumentException('Responsible user ID must be positive');
        }
        $this->responsibleUserId = $responsibleUserId;
        return $this;
    }

    public function getDueDate(): \DateTime
    {
        return $this->dueDate;
    }

    public function setDueDate(\DateTime $dueDate): self
    {
        $this->dueDate = $dueDate;
        return $this;
    }

    public function setDueDateFromString(string $dateString): self
    {
        $date = \DateTime::createFromFormat('Y-m-d', $dateString);
        if ($date === false) {
            throw new \InvalidArgumentException('Invalid date format. Use Y-m-d');
        }
        return $this->setDueDate($date);
    }

    public function getStatus(): string
    {
        return $this->status;
    }

    public function setStatus(string $status): self
    {
        if (!in_array($status, self::$validStatuses, true)) {
            throw new \InvalidArgumentException('Invalid status');
        }
        if (!in_array($status, self::$allowedTransitions[$this->status], true)) {
            throw new \RuntimeException(
                sprintf('Cannot transition from %s to %s', $this->status, $status)
            );
        }
        $this->status = $status;
        $this->updatedAt = new \DateTime();
        return $this;
    }

    public function getResult(): ?string
    {
        return $this->result;
    }

    public function setResult(?string $result): self
    {
        if ($result !== null && strlen($result) > 5000) {
            throw new \InvalidArgumentException('Result cannot exceed 5000 characters');
        }
        $this->result = $result;
        return $this;
    }

    public function getCompletedAt(): ?\DateTime
    {
        return $this->completedAt;
    }

    public function getCreatedAt(): \DateTime
    {
        return $this->createdAt;
    }

    public function getUpdatedAt(): \DateTime
    {
        return $this->updatedAt;
    }

    public function markInProgress(): self
    {
        return $this->setStatus(self::STATUS_IN_PROGRESS);
    }

    public function markComplete(string $result): self
    {
        $result = trim($result);
        if (empty($result)) {
            throw new \InvalidArgumentException('Result is required to complete action');
        }
        $this->setResult($result);
        $this->status = self::STATUS_COMPLETED;
        $this->completedAt = new \DateTime();
        $this->updatedAt = new \DateTime();
        return $this;
    }

    public function cancel(): self
    {
        return $this->setStatus(self::STATUS_CANCELLED);
    }

    public function isOverdue(): bool
    {
        if (in_array($this->status, [self::STATUS_COMPLETED, self::STATUS_CANCELLED], true)) {
            return false;
        }
        $today = new \DateTime('today');
        return $this->dueDate < $today;
    }

    public function getDaysUntilDue(): int
    {
        $today = new \DateTime('today');
        $diff = $this->dueDate->diff($today);
        return (int) $diff->format('%r%d');
    }

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'failure_mode_id' => $this->failureModeId,
            'action_description' => $this->actionDescription,
            'responsible_user_id' => $this->responsibleUserId,
            'due_date' => $this->dueDate->format('Y-m-d'),
            'status' => $this->status,
            'result' => $this->result,
            'completed_at' => $this->completedAt ? $this->completedAt->format('Y-m-d H:i:s') : null,
            'created_at' => $this->createdAt->format('Y-m-d H:i:s'),
            'updated_at' => $this->updatedAt->format('Y-m-d H:i:s'),
        ];
    }
}
```
