## Functional Requirement

### Related BR
BR-QC-003-calibration

### Description

The system SHALL automatically calculate and manage calibration due dates based on device intervals and last calibration date.

### Preconditions

1. Device exists with calibration interval set
2. Either last_calibration_date or initial calibration date is set

### Postconditions

1. Next due date calculated correctly
2. Due date updated after each calibration record
3. Overdue status correctly determined

### Functional Specification

#### 1. Scheduling Rules

| Interval | Months | Days Calculation |
|----------|--------|-----------------|
| Monthly | 1 | last_calibration_date + 1 month |
| Quarterly | 3 | last_calibration_date + 3 months |
| Semiannual | 6 | last_calibration_date + 6 months |
| Annual | 12 | last_calibration_date + 12 months |

#### 2. Business Rules

- Next due date = last_calibration_date + interval months
- If no last_calibration_date, use today's date + interval
- End of month rule: if original date was last day of month, use last day of target month
- Overdue if next_due_date < today
- Due soon if next_due_date within configured reminder days (default 7)

#### 3. User Flow

```
1. Device registered with interval
2. System calculates initial next_due_date
3. Calibration performed
4. Technician records calibration date
5. System recalculates next_due_date
6. If overdue, alert generated
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Services;

class CalibrationScheduler
{
    const INTERVAL_MONTHLY = 1;
    const INTERVAL_QUARTERLY = 3;
    const INTERVAL_SEMIANNUAL = 6;
    const INTERVAL_ANNUAL = 12;

    const DEFAULT_REMINDER_DAYS = 7;

    private $intervalMap = [
        'monthly' => self::INTERVAL_MONTHLY,
        'quarterly' => self::INTERVAL_QUARTERLY,
        'semiannual' => self::INTERVAL_SEMIANNUAL,
        'annual' => self::INTERVAL_ANNUAL,
    ];

    public function calculateNextDueDate(\DateTime $lastCalibration, string $interval): \DateTime
    {
        $months = $this->getMonthsForInterval($interval);
        $nextDue = $this->addMonthsWithEndOfMonthHandling($lastCalibration, $months);
        return $nextDue;
    }

    public function getMonthsForInterval(string $interval): int
    {
        if (!isset($this->intervalMap[$interval])) {
            throw new \InvalidArgumentException("Invalid interval: {$interval}");
        }
        return $this->intervalMap[$interval];
    }

    public function addMonthsWithEndOfMonthHandling(\DateTime $date, int $months): \DateTime
    {
        $dayOfMonth = (int) $date->format('j');
        $lastDayOfMonth = (int) $date->format('t');
        $isEndOfMonth = $dayOfMonth === $lastDayOfMonth;

        $nextDue = clone $date;
        $nextDue->add(new \DateInterval("P{$months}M"));

        if ($isEndOfMonth) {
            $nextDueDay = (int) $nextDue->format('j');
            $nextDueLastDay = (int) $nextDue->format('t');
            if ($nextDueDay !== $nextDueLastDay) {
                $nextDue->setDate(
                    (int) $nextDue->format('Y'),
                    (int) $nextDue->format('n'),
                    $nextDueLastDay
                );
            }
        }

        return $nextDue;
    }

    public function getDaysUntilDue(\DateTime $nextDue): int
    {
        $today = new \DateTime('today');
        $diff = $today->diff($nextDue);
        $days = (int) $diff->format('%r%a');
        return $days;
    }

    public function isOverdue(\DateTime $nextDue): bool
    {
        return $nextDue < new \DateTime('today');
    }

    public function isDueSoon(\DateTime $nextDue, int $days = self::DEFAULT_REMINDER_DAYS): bool
    {
        if ($this->isOverdue($nextDue)) {
            return false;
        }
        $threshold = new \DateTime('today');
        $threshold->modify("+{$days} days");
        return $nextDue <= $threshold;
    }

    public function getOverdueDevices(array $devices): array
    {
        $overdue = [];
        foreach ($devices as $device) {
            if ($this->isOverdue($device->getNextDueDate())) {
                $overdue[] = $device;
            }
        }
        return $overdue;
    }

    public function getDevicesDueSoon(array $devices, int $days = self::DEFAULT_REMINDER_DAYS): array
    {
        $dueSoon = [];
        foreach ($devices as $device) {
            if ($this->isDueSoon($device->getNextDueDate(), $days)) {
                $dueSoon[] = $device;
            }
        }
        return $dueSoon;
    }

    public function calculateFromIntervalString(string $interval): int
    {
        return $this->getMonthsForInterval($interval);
    }
}
```
