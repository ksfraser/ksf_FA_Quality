# FR-QC-002-001: AMDEC Project Creation

## Version
1.0.0

## Author
KSF Development Team

## Created
2026-09-07

## Status
Approved

## Functional Requirement

### Related BR
BR-QC-002-amdec-fmea

### Description

The system SHALL allow authorized users to create a new AMDEC project with name, type (design/process), and scope definition.

### Preconditions

1. User has Quality Engineer or higher permission
2. User is logged into FrontAccounting

### Postconditions

1. AMDEC project created with unique ID
2. Project status set to 'draft'
3. Creator recorded
4. Timestamps set

### Functional Specification

#### 1. Project Creation Form

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| Project Name | string | Yes | Max 255 chars, not empty |
| Project Type | enum | Yes | 'design' or 'process' |
| Scope Description | text | No | Max 5000 chars |
| Product ID | int | No | FK to stock_items if linked |
| BOM ID | int | No | FK to bom if process type |

#### 2. Business Rules

- Project name must be unique per user
- If project_type='design', product_id SHOULD be set
- If project_type='process', bom_id SHOULD be set
- Default status is 'draft'
- Created_by = current user ID

#### 3. User Flow

```
1. Navigate to Quality > AMDEC
2. Click "New AMDEC Project"
3. Select project type (Design or Process)
4. Enter project name
5. Optionally add scope description
6. Optionally link to product/BOM
7. Save → Project created in draft status
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Entities;

class AmdecProject
{
    const TYPE_DESIGN = 'design';
    const TYPE_PROCESS = 'process';

    const STATUS_DRAFT = 'draft';
    const STATUS_ACTIVE = 'active';
    const STATUS_CLOSED = 'closed';

    /** @var int|null */
    private $id;

    /** @var string */
    private $projectName;

    /** @var string */
    private $projectType = self::TYPE_PROCESS;

    /** @var string|null */
    private $scopeDescription;

    /** @var int|null */
    private $productId;

    /** @var int|null */
    private $bomId;

    /** @var string */
    private $status = self::STATUS_DRAFT;

    /** @var int */
    private $createdBy;

    /** @var \DateTime */
    private $createdAt;

    /** @var \DateTime|null */
    private $closedAt;

    public function __construct()
    {
        $this->createdAt = new \DateTime();
    }

    public function getId(): ?int
    {
        return $this->id;
    }

    public function setId(int $id): self
    {
        $this->id = $id;
        return $this;
    }

    public function getProjectName(): string
    {
        return $this->projectName;
    }

    public function setProjectName(string $projectName): self
    {
        $projectName = trim($projectName);
        if (empty($projectName)) {
            throw new \InvalidArgumentException('Project name cannot be empty');
        }
        if (strlen($projectName) > 255) {
            throw new \InvalidArgumentException('Project name cannot exceed 255 characters');
        }
        $this->projectName = $projectName;
        return $this;
    }

    public function getProjectType(): string
    {
        return $this->projectType;
    }

    public function setProjectType(string $projectType): self
    {
        if (!in_array($projectType, [self::TYPE_DESIGN, self::TYPE_PROCESS], true)) {
            throw new \InvalidArgumentException('Invalid project type');
        }
        $this->projectType = $projectType;
        return $this;
    }

    public function getScopeDescription(): ?string
    {
        return $this->scopeDescription;
    }

    public function setScopeDescription(?string $scopeDescription): self
    {
        if ($scopeDescription !== null) {
            $scopeDescription = trim($scopeDescription);
            if (strlen($scopeDescription) > 5000) {
                throw new \InvalidArgumentException('Scope description cannot exceed 5000 characters');
            }
        }
        $this->scopeDescription = $scopeDescription;
        return $this;
    }

    public function getProductId(): ?int
    {
        return $this->productId;
    }

    public function setProductId(?int $productId): self
    {
        $this->productId = $productId;
        return $this;
    }

    public function getBomId(): ?int
    {
        return $this->bomId;
    }

    public function setBomId(?int $bomId): self
    {
        $this->bomId = $bomId;
        return $this;
    }

    public function getStatus(): string
    {
        return $this->status;
    }

    public function setStatus(string $status): self
    {
        if (!in_array($status, [self::STATUS_DRAFT, self::STATUS_ACTIVE, self::STATUS_CLOSED], true)) {
            throw new \InvalidArgumentException('Invalid status');
        }
        $this->status = $status;
        return $this;
    }

    public function getCreatedBy(): int
    {
        return $this->createdBy;
    }

    public function setCreatedBy(int $createdBy): self
    {
        $this->createdBy = $createdBy;
        return $this;
    }

    public function getCreatedAt(): \DateTime
    {
        return $this->createdAt;
    }

    public function getClosedAt(): ?\DateTime
    {
        return $this->closedAt;
    }

    public function close(): self
    {
        $this->status = self::STATUS_CLOSED;
        $this->closedAt = new \DateTime();
        return $this;
    }

    public function activate(): self
    {
        if ($this->status !== self::STATUS_DRAFT) {
            throw new \RuntimeException('Only draft projects can be activated');
        }
        $this->status = self::STATUS_ACTIVE;
        return $this;
    }

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'project_name' => $this->projectName,
            'project_type' => $this->projectType,
            'scope_description' => $this->scopeDescription,
            'product_id' => $this->productId,
            'bom_id' => $this->bomId,
            'status' => $this->status,
            'created_by' => $this->createdBy,
            'created_at' => $this->createdAt->format('Y-m-d H:i:s'),
            'closed_at' => $this->closedAt ? $this->closedAt->format('Y-m-d H:i:s') : null,
        ];
    }
}
```
