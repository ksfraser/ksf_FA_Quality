# FR-QC-002-002: Failure Mode Entry

## Version
1.0.0

## Author
KSF Development Team

## Created
2026-09-07

## Status
Approved

## Functional Requirement

### Related BR
BR-QC-002-amdec-fmea

### Description

The system SHALL allow authorized users to record failure modes within an AMDEC project, capturing item number, potential failure mode, potential effect, and potential cause.

### Preconditions

1. User has Quality Engineer or higher permission
2. AMDEC project exists and is in 'draft' or 'active' status
3. User has opened the AMDEC project

### Postconditions

1. Failure mode record created and linked to project
2. RPN initialized to 0 (awaiting S/O/D ratings)
3. Timestamp recorded

### Functional Specification

#### 1. Failure Mode Form

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| Item Number | string | Yes | Max 100 chars |
| Potential Failure Mode | text | Yes | Max 5000 chars |
| Potential Effect | text | Yes | Max 5000 chars |
| Potential Cause | text | No | Max 5000 chars |
| Current Controls | text | No | Max 5000 chars |
| Notes | text | No | Max 5000 chars |

#### 2. Business Rules

- Failure mode must be linked to an existing project
- Item number is scoped per project (unique within project)
- Effect describes impact on customer/process
- Cause describes root cause of failure mode
- RPN remains 0 until severity, occurrence, and detection are rated

#### 3. User Flow

```
1. Open existing AMDEC project
2. Click "Add Failure Mode"
3. Enter item number
4. Enter potential failure mode description
5. Enter potential effect
6. Optionally enter potential cause
7. Optionally enter current controls
8. Save → Failure mode added to project
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Entities;

class FailureMode
{
    const MIN_RATING = 1;
    const MAX_RATING = 10;

    /** @var int|null */
    private $id;

    /** @var int */
    private $projectId;

    /** @var string */
    private $itemNumber;

    /** @var string */
    private $potentialFailureMode;

    /** @var string */
    private $potentialEffect;

    /** @var int */
    private $severity = 0;

    /** @var string|null */
    private $potentialCause;

    /** @var int */
    private $occurrence = 0;

    /** @var string|null */
    private $currentControls;

    /** @var int */
    private $detection = 0;

    /** @var int */
    private $rpn = 0;

    /** @var string|null */
    private $notes;

    /** @var \DateTime */
    private $createdAt;

    /** @var \DateTime */
    private $updatedAt;

    /** @var RpnCalculator|null */
    private $rpnCalculator;

    public function __construct(?RpnCalculator $rpnCalculator = null)
    {
        $this->createdAt = new \DateTime();
        $this->updatedAt = new \DateTime();
        $this->rpnCalculator = $rpnCalculator;
    }

    public function getId(): ?int
    {
        return $this->id;
    }

    public function setId(int $id): self
    {
        $this->id = $id;
        return $this;
    }

    public function getProjectId(): int
    {
        return $this->projectId;
    }

    public function setProjectId(int $projectId): self
    {
        $this->projectId = $projectId;
        return $this;
    }

    public function getItemNumber(): string
    {
        return $this->itemNumber;
    }

    public function setItemNumber(string $itemNumber): self
    {
        $itemNumber = trim($itemNumber);
        if (empty($itemNumber)) {
            throw new \InvalidArgumentException('Item number cannot be empty');
        }
        if (strlen($itemNumber) > 100) {
            throw new \InvalidArgumentException('Item number cannot exceed 100 characters');
        }
        $this->itemNumber = $itemNumber;
        return $this;
    }

    public function getPotentialFailureMode(): string
    {
        return $this->potentialFailureMode;
    }

    public function setPotentialFailureMode(string $potentialFailureMode): self
    {
        $potentialFailureMode = trim($potentialFailureMode);
        if (empty($potentialFailureMode)) {
            throw new \InvalidArgumentException('Potential failure mode cannot be empty');
        }
        if (strlen($potentialFailureMode) > 5000) {
            throw new \InvalidArgumentException('Potential failure mode cannot exceed 5000 characters');
        }
        $this->potentialFailureMode = $potentialFailureMode;
        return $this;
    }

    public function getPotentialEffect(): string
    {
        return $this->potentialEffect;
    }

    public function setPotentialEffect(string $potentialEffect): self
    {
        $potentialEffect = trim($potentialEffect);
        if (empty($potentialEffect)) {
            throw new \InvalidArgumentException('Potential effect cannot be empty');
        }
        if (strlen($potentialEffect) > 5000) {
            throw new \InvalidArgumentException('Potential effect cannot exceed 5000 characters');
        }
        $this->potentialEffect = $potentialEffect;
        return $this;
    }

    public function getSeverity(): int
    {
        return $this->severity;
    }

    public function setSeverity(int $severity): self
    {
        if ($severity < self::MIN_RATING || $severity > self::MAX_RATING) {
            throw new \InvalidArgumentException('Severity must be between 1 and 10');
        }
        $this->severity = $severity;
        $this->recalculateRpn();
        return $this;
    }

    public function getPotentialCause(): ?string
    {
        return $this->potentialCause;
    }

    public function setPotentialCause(?string $potentialCause): self
    {
        if ($potentialCause !== null) {
            $potentialCause = trim($potentialCause);
            if (strlen($potentialCause) > 5000) {
                throw new \InvalidArgumentException('Potential cause cannot exceed 5000 characters');
            }
        }
        $this->potentialCause = $potentialCause;
        return $this;
    }

    public function getOccurrence(): int
    {
        return $this->occurrence;
    }

    public function setOccurrence(int $occurrence): self
    {
        if ($occurrence < self::MIN_RATING || $occurrence > self::MAX_RATING) {
            throw new \InvalidArgumentException('Occurrence must be between 1 and 10');
        }
        $this->occurrence = $occurrence;
        $this->recalculateRpn();
        return $this;
    }

    public function getCurrentControls(): ?string
    {
        return $this->currentControls;
    }

    public function setCurrentControls(?string $currentControls): self
    {
        if ($currentControls !== null) {
            $currentControls = trim($currentControls);
            if (strlen($currentControls) > 5000) {
                throw new \InvalidArgumentException('Current controls cannot exceed 5000 characters');
            }
        }
        $this->currentControls = $currentControls;
        return $this;
    }

    public function getDetection(): int
    {
        return $this->detection;
    }

    public function setDetection(int $detection): self
    {
        if ($detection < self::MIN_RATING || $detection > self::MAX_RATING) {
            throw new \InvalidArgumentException('Detection must be between 1 and 10');
        }
        $this->detection = $detection;
        $this->recalculateRpn();
        return $this;
    }

    public function getRpn(): int
    {
        return $this->rpn;
    }

    private function recalculateRpn(): void
    {
        if ($this->rpnCalculator !== null) {
            $this->rpn = $this->rpnCalculator->calculate(
                $this->severity,
                $this->occurrence,
                $this->detection
            );
        } else {
            $this->rpn = $this->severity * $this->occurrence * $this->detection;
        }
    }

    public function getNotes(): ?string
    {
        return $this->notes;
    }

    public function setNotes(?string $notes): self
    {
        if ($notes !== null && strlen($notes) > 5000) {
            throw new \InvalidArgumentException('Notes cannot exceed 5000 characters');
        }
        $this->notes = $notes;
        return $this;
    }

    public function getCreatedAt(): \DateTime
    {
        return $this->createdAt;
    }

    public function getUpdatedAt(): \DateTime
    {
        return $this->updatedAt;
    }

    public function setUpdatedAt(\DateTime $updatedAt): self
    {
        $this->updatedAt = $updatedAt;
        return $this;
    }

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'project_id' => $this->projectId,
            'item_number' => $this->itemNumber,
            'potential_failure_mode' => $this->potentialFailureMode,
            'potential_effect' => $this->potentialEffect,
            'severity' => $this->severity,
            'potential_cause' => $this->potentialCause,
            'occurrence' => $this->occurrence,
            'current_controls' => $this->currentControls,
            'detection' => $this->detection,
            'rpn' => $this->rpn,
            'notes' => $this->notes,
            'created_at' => $this->createdAt->format('Y-m-d H:i:s'),
            'updated_at' => $this->updatedAt->format('Y-m-d H:i:s'),
        ];
    }
}
```
