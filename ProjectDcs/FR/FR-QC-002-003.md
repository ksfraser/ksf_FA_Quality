# FR-QC-002-003: Severity/Occurrence/Detection Ratings

## Version
1.0.0

## Author
KSF Development Team

## Created
2026-09-07

## Status
Approved

## Functional Requirement

### Related BR
BR-QC-002-amdec-fmea

### Description

The system SHALL allow users to rate each failure mode across three dimensions: Severity (S), Occurrence (O), and Detection (D), each on a 1-10 scale. These ratings SHALL automatically trigger RPN calculation.

### Preconditions

1. Failure mode record exists
2. User has edit permission on the AMDEC project
3. AMDEC project is in 'active' status

### Postconditions

1. S, O, D ratings saved
2. RPN automatically recalculated
3. Updated timestamp recorded

### Functional Specification

#### 1. Rating Scales

**Severity (S) - Effect on end user/process**

| Rating | Description |
|--------|-------------|
| 1 | No effect |
| 2-3 | Minor effect, no impact on function |
| 4-5 | Moderate effect, partial function loss |
| 6-7 | High effect, system inoperable but safe |
| 8-9 | Very high effect, system inoperable, safety affected |
| 10 | Critical - potential safety issue |

**Occurrence (O) - Frequency of cause**

| Rating | Description |
|--------|-------------|
| 1 | Extremely unlikely (< 1 in 1,500,000) |
| 2-3 | Unlikely (1 in 150,000) |
| 4-5 | Moderate (1 in 15,000) |
| 6-7 | High (1 in 2,000) |
| 8-9 | Very high (1 in 300) |
| 10 | Extremely high (> 1 in 100) |

**Detection (D) - Ability to detect before reaching customer**

| Rating | Description |
|--------|-------------|
| 1 | Always detected - obvious controls |
| 2-3 | High detection - good controls |
| 4-5 | Moderate detection - adequate controls |
| 6-7 | Low detection - poor controls |
| 8-9 | Very low detection - no detection method |
| 10 | No detection - cannot be detected |

#### 2. Business Rules

- Each rating MUST be 1-10 inclusive
- Rating change triggers immediate RPN recalculation
- Zero rating is not allowed
- RPN = S × O × D (product of all three ratings)

#### 3. User Flow

```
1. Open failure mode in edit mode
2. Select Severity rating (1-10) from dropdown
3. Select Occurrence rating (1-10) from dropdown
4. Select Detection rating (1-10) from dropdown
5. View calculated RPN
6. Save → Ratings and RPN persisted
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Services;

class RpnCalculator
{
    const MIN_RATING = 1;
    const MAX_RATING = 10;
    const DEFAULT_THRESHOLD = 100;

    const RISK_LOW = 'low';
    const RISK_MEDIUM = 'medium';
    const RISK_HIGH = 'high';
    const RISK_CRITICAL = 'critical';

    /**
     * Calculate Risk Priority Number
     *
     * RPN = Severity × Occurrence × Detection
     * Range: 1-1000
     *
     * @param int $severity S rating (1-10)
     * @param int $occurrence O rating (1-10)
     * @param int $detection D rating (1-10)
     * @return int RPN value
     * @throws \InvalidArgumentException if any rating is out of range
     */
    public function calculate(int $severity, int $occurrence, int $detection): int
    {
        $this->validateRating($severity, 'Severity');
        $this->validateRating($occurrence, 'Occurrence');
        $this->validateRating($detection, 'Detection');

        return $severity * $occurrence * $detection;
    }

    /**
     * Validate a rating is within acceptable range
     *
     * @param int $rating
     * @param string $name
     * @throws \InvalidArgumentException
     */
    private function validateRating(int $rating, string $name): void
    {
        if ($rating < self::MIN_RATING || $rating > self::MAX_RATING) {
            throw new \InvalidArgumentException(
                sprintf('%s rating must be between %d and %d', $name, self::MIN_RATING, self::MAX_RATING)
            );
        }
    }

    /**
     * Determine if RPN requires action
     *
     * @param int $rpn
     * @param int $threshold
     * @return bool
     */
    public function requiresAction(int $rpn, int $threshold = self::DEFAULT_THRESHOLD): bool
    {
        return $rpn >= $threshold;
    }

    /**
     * Get risk level classification
     *
     * @param int $rpn
     * @return string
     */
    public function getRiskLevel(int $rpn): string
    {
        if ($rpn <= 20) {
            return self::RISK_LOW;
        } elseif ($rpn <= 50) {
            return self::RISK_MEDIUM;
        } elseif ($rpn <= 100) {
            return self::RISK_HIGH;
        }
        return self::RISK_CRITICAL;
    }

    /**
     * Get risk color for UI display
     *
     * @param string $riskLevel
     * @return string Hex color code
     */
    public function getRiskColor(string $riskLevel): string
    {
        switch ($riskLevel) {
            case self::RISK_LOW:
                return '#28a745';
            case self::RISK_MEDIUM:
                return '#ffc107';
            case self::RISK_HIGH:
                return '#fd7e14';
            case self::RISK_CRITICAL:
                return '#dc3545';
            default:
                return '#6c757d';
        }
    }

    /**
     * Sort failure modes by priority (highest RPN first)
     *
     * @param array $failureModes Array of FailureMode entities
     * @return array Sorted array
     */
    public function getPrioritySortOrder(array $failureModes): array
    {
        usort($failureModes, function ($a, $b) {
            return $b->getRpn() - $a->getRpn();
        });
        return $failureModes;
    }

    /**
     * Get RPN threshold
     *
     * @return int
     */
    public function getDefaultThreshold(): int
    {
        return self::DEFAULT_THRESHOLD;
    }
}
```
