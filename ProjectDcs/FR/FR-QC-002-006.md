## Functional Requirement

### Related BR
BR-QC-002-amdec-fmea

### Description

The system SHALL provide reporting capabilities for AMDEC projects, including RPN summaries, risk distribution charts, action status dashboards, and printable AMDEC worksheets.

### Preconditions

1. AMDEC project exists
2. User has view permission on the project

### Postconditions

1. Report data generated from current project state
2. Export formats available (PDF, Excel)
3. Printable worksheet generated

### Functional Specification

#### 1. Report Types

##### 1.1 RPN Summary Report

| Field | Description |
|-------|-------------|
| Total Failure Modes | Count of all failure modes |
| Average RPN | Mean RPN across all modes |
| Highest RPN | Maximum RPN value |
| Lowest RPN | Minimum RPN value |
| Modes Needing Action | Count with RPN ≥ threshold |

##### 1.2 Risk Distribution Report

| Risk Level | Count | Percentage |
|------------|-------|------------|
| Low (1-20) | X | XX% |
| Medium (21-50) | X | XX% |
| High (51-100) | X | XX% |
| Critical (101+) | X | XX% |

##### 1.3 Action Status Report

| Status | Count | Overdue |
|--------|-------|---------|
| Pending | X | X |
| In Progress | X | X |
| Completed | X | - |
| Cancelled | X | - |

##### 1.4 AMDEC Worksheet (Printable)

Complete failure mode table with:
- Item numbers
- Failure modes
- Effects
- S/O/D ratings
- RPN
- Actions
- Status

#### 2. Export Formats

| Format | Use Case |
|--------|----------|
| PDF | Printing, email attachment |
| Excel (XLSX) | Further analysis, data manipulation |

#### 3. Business Rules

- Reports reflect current data at generation time
- RPN threshold configurable per report
- Filter by risk level available
- Sort by RPN (default), severity, occurrence, or detection

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Services;

use ksfraser\FrontAccounting\Quality\Entities\AmdecProject;
use ksfraser\FrontAccounting\Quality\Entities\FailureMode;
use ksfraser\FrontAccounting\Quality\Entities\AmdecAction;

class AmdecReportGenerator
{
    /** @var RpnCalculator */
    private $rpnCalculator;

    public function __construct(RpnCalculator $rpnCalculator)
    {
        $this->rpnCalculator = $rpnCalculator;
    }

    public function generateRpnSummary(AmdecProject $project, array $failureModes): array
    {
        if (empty($failureModes)) {
            return [
                'total_failure_modes' => 0,
                'average_rpn' => 0,
                'highest_rpn' => 0,
                'lowest_rpn' => 0,
                'modes_needing_action' => 0,
            ];
        }

        $rpns = array_map(function (FailureMode $fm) {
            return $fm->getRpn();
        }, $failureModes);

        $threshold = $this->rpnCalculator->getDefaultThreshold();

        return [
            'total_failure_modes' => count($failureModes),
            'average_rpn' => array_sum($rpns) / count($rpns),
            'highest_rpn' => max($rpns),
            'lowest_rpn' => min($rpns),
            'modes_needing_action' => count(array_filter($rpns, function ($rpn) use ($threshold) {
                return $rpn >= $threshold;
            })),
        ];
    }

    public function generateRiskDistribution(array $failureModes): array
    {
        $distribution = [
            RpnCalculator::RISK_LOW => ['count' => 0, 'percentage' => 0],
            RpnCalculator::RISK_MEDIUM => ['count' => 0, 'percentage' => 0],
            RpnCalculator::RISK_HIGH => ['count' => 0, 'percentage' => 0],
            RpnCalculator::RISK_CRITICAL => ['count' => 0, 'percentage' => 0],
        ];

        if (empty($failureModes)) {
            return $distribution;
        }

        foreach ($failureModes as $fm) {
            $level = $this->rpnCalculator->getRiskLevel($fm->getRpn());
            $distribution[$level]['count']++;
        }

        $total = count($failureModes);
        foreach ($distribution as $level => $data) {
            $distribution[$level]['percentage'] = round(($data['count'] / $total) * 100, 1);
        }

        return $distribution;
    }

    public function generateActionStatus(array $actions): array
    {
        $statusCounts = [
            AmdecAction::STATUS_PENDING => ['total' => 0, 'overdue' => 0],
            AmdecAction::STATUS_IN_PROGRESS => ['total' => 0, 'overdue' => 0],
            AmdecAction::STATUS_COMPLETED => ['total' => 0, 'overdue' => 0],
            AmdecAction::STATUS_CANCELLED => ['total' => 0, 'overdue' => 0],
        ];

        foreach ($actions as $action) {
            $status = $action->getStatus();
            $statusCounts[$status]['total']++;
            if ($action->isOverdue()) {
                $statusCounts[$status]['overdue']++;
            }
        }

        return $statusCounts;
    }

    public function generateWorksheetData(AmdecProject $project, array $failureModes): array
    {
        $worksheet = [
            'project' => [
                'name' => $project->getProjectName(),
                'type' => $project->getProjectType(),
                'status' => $project->getStatus(),
                'created_at' => $project->getCreatedAt()->format('Y-m-d H:i:s'),
            ],
            'failure_modes' => [],
        ];

        foreach ($failureModes as $fm) {
            $worksheet['failure_modes'][] = [
                'item_number' => $fm->getItemNumber(),
                'failure_mode' => $fm->getPotentialFailureMode(),
                'effect' => $fm->getPotentialEffect(),
                'severity' => $fm->getSeverity(),
                'cause' => $fm->getPotentialCause(),
                'occurrence' => $fm->getOccurrence(),
                'controls' => $fm->getCurrentControls(),
                'detection' => $fm->getDetection(),
                'rpn' => $fm->getRpn(),
                'risk_level' => $this->rpnCalculator->getRiskLevel($fm->getRpn()),
                'notes' => $fm->getNotes(),
            ];
        }

        return $worksheet;
    }
}
```
