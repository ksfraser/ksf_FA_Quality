## Version

## Author
KSF Development Team

## Created

## Status
Proposed

## Functional Requirement

### Related BR
BR-QC-003-calibration

### Description

The system SHALL generate and manage alerts for upcoming calibrations, overdue calibrations, and devices that have been found out-of-tolerance during calibration.

### Preconditions

1. Device exists with next_due_date set
2. OR calibration record created with out_of_tolerance result

### Postconditions

1. Alert created with unique ID
2. Alert type correctly assigned
3. Alert can be acknowledged by authorized user

### Functional Specification

#### 1. Alert Types

| Alert Type | Constant | Trigger | Priority |
|------------|----------|---------|----------|
| Due Soon | `calibration_due_soon` | next_due_date within reminder days | Medium |
| Overdue | `calibration_overdue` | next_due_date < today | High |
| Out of Tolerance | `device_out_of_tolerance` | record result = out_of_tolerance | Critical |

#### 2. Alert Record Fields

| Field | Type | Description |
|-------|------|-------------|
| Alert ID | int | Unique identifier |
| Device ID | int | FK to calibration_devices |
| Record ID | int | FK to calibration_records (nullable) |
| Alert Type | enum | Type of alert |
| Alert Date | date | Date alert was generated |
| Alert Sent | datetime | When notification was sent |
| Alert Destination | string | Email/notification target |
| Message | text | Alert message |
| Acknowledged | bool | Has user acknowledged |
| Acknowledged By | int | User who acknowledged |
| Acknowledged At | datetime | When acknowledged |

#### 3. Business Rules

- Due soon alerts generated daily (batch job)
- Overdue alerts generated on due date transition
- Out-of-tolerance alerts generated immediately on record save
- Only one active due_soon alert per device
- Only one active overdue alert per device
- Multiple out_of_tolerance alerts allowed (one per incident)
- Acknowledged alerts marked as closed

#### 4. Alert Generation Triggers

```
1. Daily batch job scans all active devices
2. If next_due_date < today AND no active overdue alert → create overdue alert
3. If next_due_date within reminder days AND no active due_soon alert → create due_soon alert
4. On calibration record save with result = out_of_tolerance → create out_of_tolerance alert
```

### PHP 7.3 Compatible Code

```php
<?php
declare(strict_types=1);

namespace ksfraser\FrontAccounting\Quality\Services;

use ksfraser\FrontAccounting\Quality\Entities\CalibrationDevice;

class AlertService
{
    const ALERT_DUE_SOON = 'calibration_due_soon';
    const ALERT_OVERDUE = 'calibration_overdue';
    const ALERT_OUT_OF_TOLERANCE = 'device_out_of_tolerance';

    const PRIORITY_MEDIUM = 'medium';
    const PRIORITY_HIGH = 'high';
    const PRIORITY_CRITICAL = 'critical';

    const VALID_ALERT_TYPES = [
        self::ALERT_DUE_SOON,
        self::ALERT_OVERDUE,
        self::ALERT_OUT_OF_TOLERANCE,
    ];

    private $scheduler;
    private $dao;

    public function __construct(
        CalibrationScheduler $scheduler = null,
        ?CalibrationDao $dao = null
    ) {
        $this->scheduler = $scheduler ?: new CalibrationScheduler();
        $this->dao = $dao;
    }

    public function setDao(CalibrationDao $dao): void
    {
        $this->dao = $dao;
    }

    public function createAlert(
        int $deviceId,
        string $alertType,
        ?int $recordId = null
    ): int {
        if (!in_array($alertType, self::VALID_ALERT_TYPES, true)) {
            throw new \InvalidArgumentException("Invalid alert type: {$alertType}");
        }

        if ($alertType === self::ALERT_DUE_SOON) {
            $message = 'Calibration due within ' . $this->scheduler::DEFAULT_REMINDER_DAYS . ' days';
        } elseif ($alertType === self::ALERT_OVERDUE) {
            $message = 'Calibration is overdue';
        } else {
            $message = 'Device found out-of-tolerance during calibration';
        }

        $alertDate = new \DateTime('today');

        if ($this->dao !== null) {
            return $this->dao->insertAlert([
                'device_id' => $deviceId,
                'record_id' => $recordId,
                'alert_type' => $alertType,
                'alert_date' => $alertDate->format('Y-m-d'),
                'message' => $message,
                'acknowledged' => 0,
            ]);
        }

        return 0;
    }

    public function getPendingAlerts(): array
    {
        if ($this->dao === null) {
            return [];
        }
        return $this->dao->getPendingAlerts();
    }

    public function markAlertSent(int $alertId): bool
    {
        if ($this->dao === null) {
            return false;
        }
        return $this->dao->updateAlertSent($alertId, new \DateTime());
    }

    public function getAlertsForDevice(int $deviceId): array
    {
        if ($this->dao === null) {
            return [];
        }
        return $this->dao->getAlertsForDevice($deviceId);
    }

    public function shouldSendReminder(CalibrationDevice $device): bool
    {
        $nextDue = $device->getNextDueDate();
        return $this->scheduler->isDueSoon($nextDue)
            || $this->scheduler->isOverdue($nextDue);
    }

    public function getAlertPriority(string $alertType): string
    {
        switch ($alertType) {
            case self::ALERT_OUT_OF_TOLERANCE:
                return self::PRIORITY_CRITICAL;
            case self::ALERT_OVERDUE:
                return self::PRIORITY_HIGH;
            case self::ALERT_DUE_SOON:
            default:
                return self::PRIORITY_MEDIUM;
        }
    }

    public function hasActiveAlertForDevice(int $deviceId, string $alertType): bool
    {
        if ($this->dao === null) {
            return false;
        }
        if ($alertType === self::ALERT_OUT_OF_TOLERANCE) {
            return false;
        }
        return $this->dao->hasActiveAlert($deviceId, $alertType);
    }

    public function acknowledgeAlert(int $alertId, int $userId): bool
    {
        if ($this->dao === null) {
            return false;
        }
        return $this->dao->acknowledgeAlert($alertId, $userId);
    }

    public function generateBatchAlerts(array $devices): array
    {
        $generated = [];
        foreach ($devices as $device) {
            $nextDue = $device->getNextDueDate();

            if ($this->scheduler->isOverdue($nextDue)) {
                if (!$this->hasActiveAlertForDevice($device->getId(), self::ALERT_OVERDUE)) {
                    $alertId = $this->createAlert($device->getId(), self::ALERT_OVERDUE);
                    $generated[] = $alertId;
                }
            } elseif ($this->scheduler->isDueSoon($nextDue)) {
                if (!$this->hasActiveAlertForDevice($device->getId(), self::ALERT_DUE_SOON)) {
                    $alertId = $this->createAlert($device->getId(), self::ALERT_DUE_SOON);
                    $generated[] = $alertId;
                }
            }
        }
        return $generated;
    }
}
```
